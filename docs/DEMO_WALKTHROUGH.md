# Demo walkthrough (Milestone 4) - reproducible

Everything below is synthetic and offline. The table is generated by running the real service on the shipped
calibrated policy (`cal-2026-10-27-v1`, lexical-only mode); the screenshots are real captures of the running app.

> **Note (Milestone 5):** the three screenshots below were captured on Gradio 6.10.0. The demo was later upgraded to Gradio 6.30.0 for security fixes (see governance/DEPENDENCY_REPORT.md) and the UI was re-checked in a real browser: it renders identically and the tour below is unchanged. The screenshots are preserved as captured.

## Run it
`
cd governed-claims-engine
.venv\Scripts\python -m claims_engine.app            # lexical-only; http://127.0.0.1:7860
.venv\Scripts\python -m claims_engine.app --semantic  # also use the local multilingual model (needs models/ fetched)
.venv\Scripts\python -m claims_engine.app --port 7861 --audit-log demo_logs\audit.jsonl
.venv\Scripts\python -m claims_engine.app --audit-log demo_logs\audit.jsonl --tamper-evident   # hash-chained log
.venv\Scripts\python -m claims_engine.audit_chain verify demo_logs\audit.jsonl
`
Binds to 127.0.0.1 only; no share link; no uploads; analytics/version-check disabled; strict CSP; system fonts.

## Suggested 3-minute tour
1. **Tab 1 - Assess.** Keep `synthetic_home_policy.pdf` selected (the scope panel lists exactly what may be searched/cited), load example 1, press **Assess**.
   You get a green *SUPPORTED PRELIMINARY ASSESSMENT* card, the cited clause (3.1, page 3, document version + hash) and its exact excerpt, the uncertainty, and a collapsed list of other passages that were considered but NOT cited.
   Screenshot: `docs/screenshot_1_supported_assessment.jpg`.
2. Load examples 4, 5, 9 and 10 to see the other outcomes: red *HUMAN REVIEW REQUIRED* (exception wording; limit-only clause; instruction hidden in the question; injected text inside a policy clause - that passage is quarantined and never shown) and grey *INSUFFICIENT EVIDENCE* (examples 6-8).
3. **Tab 2 - Human review (demonstration).** The original proposal is shown unchanged. Choose *Override*, press **Record review** with no explanation: refused. Pick a status, type an explanation (>= 10 characters), record: you get a *RECORDED DEMONSTRATION REVIEW* card showing proposed vs effective status, the pseudonymous reviewer id, the timestamp, and the notice that it is not a legally binding insurance decision.
   Screenshot: `docs/screenshot_2_review_override.jpg`.
4. **Tab 3 - Audit.** Pick the trace: trace id, document filename + version + SHA-256, retrieved evidence ids, guardrail flags, workflow path, the SHA-256 of the question (the question text itself is not stored) and the review history.
   Screenshot: `docs/screenshot_3_audit_viewer.jpg`.
5. **About & limitations** repeats the banner that is also shown on every tab.
